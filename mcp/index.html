Model Context Protocol (MCP) Developer Guide

The Model Context Protocol (MCP) is an open standard created by Anthropic that standardizes how artificial intelligence applications (clients) discover, authenticate, and interact with external data sources, prompts, and executable tools (servers).

Core Primitives

  • Tools: Executable functions with JSON-Schema parameter definitions.
  • Resources: Read-only data payloads similar to files or database rows for LLM context ingestion.
  • Prompts: Pre-packaged prompt workflows and instructions.

MCP vs Traditional Function Calling

Unlike proprietary function calling schemas tied to a single model provider, MCP provides a decoupled client-server architecture: build an MCP server once and consume it across Claude Desktop, Cursor, Antigravity, and custom agent runtimes.
