## 🤖 Generative Engine Optimization (GEO) & Machine-Readable Standards

This repository implements the emerging standard for AI search discovery and large language model ingestion:

* **[`/llms.txt`](https://abhishek4official.github.io/llms.txt)**: Concise, token-efficient Markdown index following the [llmstxt.org](https://llmstxt.org) standard for Claude, ChatGPT Search, and Perplexity.
* **[`/llms-full.txt`](https://abhishek4official.github.io/llms-full.txt)**: Full concatenated technical corpus for large context window reasoning models.
* **[`/robots.txt`](https://abhishek4official.github.io/robots.txt)**: AI search bot crawler policy explicitly authorizing `OAI-SearchBot`, `ChatGPT-User`, `PerplexityBot`, and `Claude-SearchBot`.
* **Universal Schema.org Knowledge Graph**: Injected JSON-LD graph linking `Person`, `WebSite`, `TechArticle`, `SoftwareApplication`, and `BreadcrumbList`.

## 🏗️ Architecture & Development

```bash
# Clone the repository
git clone https://github.com/abhishek4official/abhishek4official.github.io.git
cd abhishek4official.github.io/src

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production (TypeScript + Vite + Static Post-Build Generator)
npm run build
```

The build pipeline features a custom static pre-rendering engine (`postbuild.js`) that produces both an interactive React 19 SPA and pre-rendered static HTML directories, ensuring search engine bots and AI discovery agents receive complete semantic text without executing JavaScript.
